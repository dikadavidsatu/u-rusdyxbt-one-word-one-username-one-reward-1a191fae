One word, one username, one reward. This entry is a tiny deterministic program that writes the entrant's own make.fun username — `dikadavidsatu` — as a single word to `entry.txt` and nothing else. No explanation, no links, no pitch: the judge reads two usernames at a time and picks the funnier or more interesting one, and the first thing it weighs is whether the text is a real make.fun handle, the entrant's own. So the program sends exactly that handle, after checking it against the published gate (1–30 characters, a single word, not only white space) and reading the file back to prove what landed on disk is byte-for-byte the handle it meant to send. It uses only Node built-ins and produces byte-identical output on every run. Bounty: https://make.fun/bounty/u-rusdyxbt-one-word-one-username-one-reward-1a191fae

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
