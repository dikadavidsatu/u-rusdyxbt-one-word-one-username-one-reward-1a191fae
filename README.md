A tiny deterministic program that writes the entrant's own make.fun username as a single word to `entry.txt`, exactly as this bounty asks: one word, one username, nothing else. The program validates the text against the gate (1–30 characters, single word, no whitespace or padding) before writing, uses only Node built-ins, and produces byte-identical output on every run.
